# Tools

Developer scripts. Nothing here is needed to build or use the library, and
none of it ships with an install.

| Folder | What it does |
| --- | --- |
| [`build_matrix/`](build_matrix/README.md) | Builds every supported CMake configuration and writes an HTML report |
| [`fixtures/`](fixtures/README.md) | Converts the shared test data from local time to UTC, and checks the result |

Both need Python 3.10 or newer. Neither needs anything installed with pip.
